# AI Prompts and Notes

We used AI (Claude) to help make the PlanX logo, launch screen, app icon and empty state pictures. This file says what we asked for so the work is easy to check.

## What we asked for

- A modern, original, cartoony graffiti look that feels playful, in the same spirit as a bright cartoon but not copying any show, character or brand
- App name PlanX, wordmark in Lilita One (open source Google Font), the X in Lime so it stands out
- Colours only from `design/design-standards.md`: Grape, Bubblegum, Lime, Aqua, Deep Ink, Cream
- Thick 2px style outlines, hard offset shadows, a slight sticker tilt
- Paint splats and drips only as decoration, never behind text or buttons

## What was made

| File group | Direction we gave |
|---|---|
| `logo/logo-primary`, `logo-dark` | Wordmark on a Grape sticker with a paint splat. Dark version uses a lighter Grape so it still shows on Deep Ink |
| `logo/logo-mark`, `icon-app`, `icon-app-adaptive` | Just the X on a rounded square. Adaptive icon keeps the X inside the Android safe zone |
| `illustrations/launch-screen` | Grape background, wordmark in the middle, splats in the corners, 1080 x 1920 |
| `illustrations/empty-tasks`, `empty-schedule`, `empty-transcripts` | A clipboard, a calendar and a speech bubble on a paint splat, matching the three tabs |
| `illustrations/splat-*` | Single splats in Grape, Bubblegum, Lime and Aqua |

## Checks we did

- Looked at every file on light, dark and Grape backgrounds
- Nothing copies an existing character, logo or picture
- Edited and approved by the team before use (team to confirm)

## Update: recording and voice hint in the logo

We asked for a small hint of the recording and voice feature in the logo. The X now has a small red record button (Tomato `#FF4B4B` dot) at its top right with two curved sound waves next to it, like a voice recording light. It is in the wordmark logos, the mark, the app icon, the adaptive icon and the launch screen. The pink splat in the logo was changed to Aqua so the red dot is the only red thing.
