# User Flows

Exported flow diagrams go here (PNG or PDF), one file per flow.

- Name them `flow-<what the user does>.png`, for example `flow-record-meeting.png` or `flow-add-task.png`
- Each flow shows the user story, where the user starts, the actions and decisions, the screens, and where tab and stack navigation are used
- Alternate paths go on the same diagram (for example microphone permission denied, no internet, transcription failed)
