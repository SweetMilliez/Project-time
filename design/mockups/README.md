# Mockups

Exported mockups go here, one picture per screen.

- Name them `screen-<name>.png`, for example `screen-login.png` or `screen-tasks.png`
- If we make a dark version, add `-dark` (for example `screen-tasks-dark.png`)
- Every mockup is linked on that screen's Kanban ticket, next to its flow notes
- Mockups use the colours, fonts and icons from `design/design-standards.md` and the layout from `design/screen-template.md`
- If AI helped make a mockup, the prompt goes in `design/ai-prompts.md`
